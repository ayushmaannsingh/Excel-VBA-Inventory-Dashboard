# 📦 Inventory Performance Dashboard — Excel VBA

A fully automated, one-click Excel dashboard that converts raw 
inventory data into a professional Business Intelligence report 
using pure VBA — no Power BI, no Python, no plugins needed.

## ✨ Features

- ✅ Auto-creates **5 Pivot Tables** from raw data
- ✅ Builds **6 Dynamic Charts** (Line, Pie, Bar, Area, Combo, Stacked)
- ✅ Displays **5 KPI Cards** (Revenue, Profit, Units Sold, Expenses, Margin)
- ✅ **3 Interactive Slicers** (Month, Supplier, Category)
- ✅ Professional color-coded layout
- ✅ Full error handling & modular code structure
- ✅ One-click execution — just run `CreateInventoryDashboard()`
